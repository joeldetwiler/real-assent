# Real Assent

A register of what you actually believe — atomic commitments ratified one at a time, headline
positions derived from them, and contradictions caught the moment a new commitment is entered.

The name is from Newman's *An Essay in Aid of a Grammar of Assent*, which distinguishes **notional
assent** (an abstract nod, agreement in principle) from **real assent** (a belief actually held and
acted on). Only the second kind is worth keeping a register of.

## Why it exists

Writing beliefs down is easy and a plain text file does it well. What a text file cannot do is check
sixty commitments against each other. That check is the product.
